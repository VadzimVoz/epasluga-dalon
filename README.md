# Е-Паслуга — прототип личного кабинета (срез 2: редизайн + «Далонь»)

Статический прототип личного кабинета гражданина на Едином портале электронных услуг. Без сборки и фреймворков: `index.html`, чистый CSS и vanilla JS. Данные условные, оплата демонстрационная, состояние хранится в `localStorage` браузера.

## Как запустить

Прототип — обычные HTML, CSS и JS. Ничего устанавливать через npm и собирать не нужно. Нужен только браузер и, для рекомендуемого способа, Python 3. Для шрифтов нужен интернет; без него страница откроется, но системным шрифтом.

### 1. Скачать проект

**Без git:** на странице репозитория нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив в любую папку.

**С git:**

```bash
git clone https://github.com/VadzimVoz/epasluga-dalon.git
cd epasluga-dalon
```

### 2. Запустить

**Windows.** Дважды щёлкните `start.bat` в папке проекта. Откроется чёрное окно и браузер со страницей http://127.0.0.1:4173/. Окно не закрывайте, пока смотрите прототип.

Если появилось «Python не найден» — установите Python 3 с https://www.python.org/downloads/ и при установке отметьте галочку **Add python.exe to PATH**. Потом снова запустите `start.bat`.

**macOS и Linux.** Откройте терминал в папке проекта и выполните:

```bash
./start.sh
```

Если пишет `Permission denied` — сначала `chmod +x start.sh`. На macOS браузер сам не откроется: перейдите на http://127.0.0.1:4173/ вручную. Если Python 3 нет: на macOS `xcode-select --install` или `brew install python`, на Ubuntu/Debian `sudo apt install python3`.

**Вручную, любая система.** В терминале в папке проекта:

```bash
python -m http.server 4173 --bind 127.0.0.1
```

(на macOS/Linux — `python3`), затем откройте http://127.0.0.1:4173/.

**Без Python.** Подойдёт любой статический сервер, например при установленном Node.js:

```bash
npx serve -l 4173 .
```

или расширение **Live Server** в VS Code (правый клик по `index.html` → Open with Live Server).

### 3. Посмотреть

- При первом заходе откроется экран входа — **любой способ входа пускает в кабинет**, вводить настоящие данные не нужно.
- Всё демонстрационное: персона, суммы, оплата. Ничего никуда не отправляется, состояние хранится только в вашем браузере (`localStorage`).
- Чтобы начать демо с чистого листа: F12 → **Application** (в Firefox — **Хранилище**) → **Clear site data**, затем обновите страницу. Или откройте прототип в окне инкогнито.
- Мобильную версию можно посмотреть в самом браузере: F12 → значок телефона (Toggle device toolbar) → выберите, например, iPhone.
- Остановить сервер: в окне терминала нажмите **Ctrl+C** или просто закройте его.

### Если не открывается

- **Порт 4173 занят** («Address already in use»): запустите на другом порту, например `python -m http.server 5000 --bind 127.0.0.1`, и откройте http://127.0.0.1:5000/.
- **Видны старые экраны после обновления:** обновите страницу с очисткой кэша — **Ctrl+F5** (на macOS **Cmd+Shift+R**).
- **Пустая страница:** проверьте, что открываете адрес `http://127.0.0.1:...`, а не файл из папки, и что окно с сервером не закрыто.

## Маршруты

| Адрес | Экран |
| --- | --- |
| `#/login` | Вход: пароль + SMS, биометрия / М-ЭЦП, ID-карта (демо) |
| `#/` | Главная: поиск, «Требует внимания», жизненные ситуации, справки без ID-карты, новости |
| `#/catalog` | Услуги по категориям |
| `#/catalog?view=list` | Все услуги (поиск, код, темы, страницы) |
| `#/catalog?view=list&life=job` | Услуги жизненной ситуации (`job`, `move`, `study`, `baby`, `business`, `pets`, `car`, `license`) |
| `#/catalog?view=favs` | Избранное |
| `#/service/<код>` | Карточка услуги и заявление |
| `#/apps` | Мои услуги: «Нужно ваше действие», «На рассмотрении», «Завершены» |
| `#/inbox`, `#/inbox?box=arch` | Уведомления и архив, фильтр `kind=legal` / `kind=info` |
| `#/profile` | Мой профиль |
| `#/more` | Мобильное меню «Ещё» |
| `#/dalon` | Далонь: панель семьи, начисления, сроки, оплата выбранного |
| `#/dalon/reminders` | Далонь: напоминания и их настройки |
| `#/dalon/family` | Далонь: семья и права (видит / платит, согласия) |
| `#/dalon/pay?ids=…` | Далонь: подтверждение оплаты, демо-успех и демо-сбой |
| `#/dalon/history` | Далонь: история платежей и квитанции |

## Что сделано в срезе 2

**Общий редизайн.** Шрифт Onest (Google Fonts, полная кириллица) — геометрический гротеск, близкий по духу к Muller, которым набран сам портал. Основа нейтральная: тёплый off-white фон, графитовый текст, белые карточки. Один приглушённый акцент — синий, производный от фирменного `#293394`, — только на главных кнопках, активном пункте и ключевых цифрах. Базовый кегль 17 px, вспомогательный текст не светлее `#6c6c74` (контраст на белом выше 4,5:1), кнопки и поля высотой от 42 px. Экраны собраны по-разному: поисковая главная с лентой сроков, указатель категорий, список услуг строками, «чек» оплаты, дорожки статусов заявлений, карточка-документ в профиле.

**«Далонь» — семейный раздел** («Всё о семье — в одной ладони»). Панель-ладонь: пять «пальцев» — Алексей, Анна, Маша, Миша и автомобиль — и сумма к оплате на «ладони». Начисления по каждому члену семьи с чекбоксами, календарь и лента сроков, липкая панель «Оплатить выбранные». Напоминания (скидка 50% на штраф ГАИ, техосмотр, налог, садик, кружок, срок паспорта) и настройки каналов. Семья и права: роли «видит» / «платит», согласия «ожидает / дано / отозвать», законные представители детей, добавление взрослого с запросом согласия. Оплата через ЕРИП или карту: плашка «деньги не хранятся в Е-Паслуге», демо-сбой с текстом «Платёж не прошёл. Деньги не списаны» и кнопкой «Повторить». Оплаченное пропадает из панели и попадает в историю; квитанции скачиваются (демо-HTML). Бордо и оранжевый приглушены и стоят только акцентами: логотип раздела, метки, одна главная кнопка на экран. Текст на оранжевом — тёмно-бордовый.

**Новая главная.** Большой поиск с подсказками и синонимами. Блок «Требует внимания»: ближайшие начисления из Далони, заявления, ждущие оплаты, черновики и готовые документы. Плитки жизненных ситуаций, крупнее — чаще встречающиеся по опросу (работа и справки 57%, переезд 47%, учёба 46%…); каждая открывает каталог с фильтром ситуации. Отдельная полоса «Можно без ID-карты и ЭЦП». Новости — компактным раскрывающимся списком внизу.

**Вход.** Три способа и подпись, что даёт каждый: просмотр начислений и справок — без ЭЦП; ЭЦП — только для юридически значимых действий. Подсказки на случай, если ID-карта не считывается. Кнопка «Выйти» в шапке возвращает на вход.

**Мобильная раскладка (≤ 900 px).** Нижняя панель вкладок «Главная / Услуги / Далонь / Заявления / Ещё», поля 16 px при ширине ≤ 640 px, без горизонтальной прокрутки.

**Антифрод.** Плашка «Мы никогда не просим коды из SMS и не присылаем ссылки на оплату» — в уведомлениях, на входе, в профиле, на подтверждении оплаты и в настройках напоминаний.

**Чистка меню.** Нерабочие разделы (деловая репутация, ЕС ИФЮЛ, активация кабинета организации, репозиторий документов и др.) убраны в свёрнутое «Ещё — скоро» как обычный текст, без кнопок-пустышек. Кнопка «Обратная связь», которая ничего не делала, удалена.

**Что сохранено из среза 1.** Человеческие названия, официальная формулировка и код вторым планом; поиск с синонимами и подсказками (теперь совпадения по синониму и названию стоят выше); бейджи «Без ID-карты» и «ЭЦП — нужна подпись»; категории; избранное; карточка «Что вы получите»; форма с живой валидацией и автосохранением черновика; «Мои услуги» со статусами и демо-оплатой; уведомления с архивом.

## Файлы

- `index.html` — подключение шрифтов Google Fonts, стилей и скриптов
- `css/styles.css` — токены, оболочка, общие компоненты, экраны кабинета
- `css/login.css` — экран входа
- `css/dalon.css` — раздел «Далонь»
- `js/app.js` — маршрутизация, оболочка, главная, каталог, услуга, заявления, уведомления, профиль
- `js/login.js` — экран входа
- `js/dalon.js` — раздел «Далонь»
- `js/data.js` — услуги, ситуации, синонимы (генерируется `generate_data.py`)

Описания сроков и стоимости услуг — заглушки до регламентов. Суммы, адреса и учреждения в Далони — условные.
